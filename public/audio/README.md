# Aurelka meows

- `aurelka-meow-decisive.mp3` — Aurelka's decisive, unhappy meow. It is always
  used when both WAN links are unavailable.
- `aurelka-meow-gentle.mp3` — Aurelka's gentler meow.
- `aurelka-purr-relaxing.mp3` — a clean, softly processed ambient purr loop,
  played at low volume only while both WAN links are healthy. Source:
  [cat purring loop.wav by soundofsong](https://freesound.org/people/soundofsong/sounds/650575/),
  released under CC0 1.0.

When exactly one WAN link is unavailable, the panel randomly selects one of
the two meow recordings. When both links are healthy, the relaxing purr fades
in and loops quietly; it fades out when a link is being checked or has failed.
The two meow recordings feature the real Aurelka and are used with the owner's
permission.
