Administrative panel

Built for ASUS RT-N18U with the unofficial gzenux Asuswrt-Merlin RT-N18U firmware version 386.3_3. Most applied settings continue on the router when the panel is stopped: SmartWAN rules and presets, watchdog/failover, managed VPN/DMZ policy, and Merlin hooks.

Keep the container running for WAN country/location checks, Cloudflare DDNS, Tailscale, persistent WAN-event archiving, public status/network map, and Aurelka notifications.

SmartWAN

Presets, domain/CIDR/source rules, 1-second default watchdog, 2 failures to switch, 3 successes to return.

ASUS Dual WAN

Port roles, load balance or failover, ratios, service groups, validation, and conflict previews.

VPN and remote access

OpenVPN Server 1/2 policy and profiles, Tailscale subnet routing, and Cloudflare DDNS.

Safety

Ed25519 keys, host fingerprint checks, automatic backups, restore preview, and managed Merlin hook blocks.

Dashboard

Router resources, WAN health, Internet probes, persistent events, logs, and route visualization.

Network map

Read-only trusted-LAN preview, active devices, per-device route, WAN state, and VPN downloads.

Managed DMZ

WAN-aware inbound and return routing with failover-follow or preferred-WAN-only behavior.

Guided setup

Model/firmware detection, diff preview, safety backup, confirmation, script install, and apply.

Aurelka — guardian of both WAN links

Each eye represents one WAN. Green means healthy; orange means checking, stale data, or recovery confirmation; red means that WAN is down. Aurelka identifies the failed link, changes her expression and bulb, and—when sound is enabled—meows twice and repeats every 30 seconds during an outage. New local messages and WAN state changes also pulse the notification bulb.

Login screen

There is no factory password. The owner creates it from the Docker host. The page provides username/password login, a signed 12-hour HttpOnly session, language selection, Aurelka controls, password-reset instructions, expandable connection status, and a trusted-network read-only map preview. 

docker compose exec smartwan-manager node server/setPanelPassword.js admin 'replace-with-a-strong-password'

Install on Raspberry Pi, Ubuntu, or WSL 2

Recommended: 64-bit Linux, 2 GB RAM, 2 GB free storage, Docker Engine with Compose v2, Git, wired LAN, and SSH reachability to the router. A Pi 3B+ with 1 GB and swap is a practical minimum; Pi 4/5 with 2 GB+ is preferred. 

git clone https://github.com/hattimon/SmartWAN-Manager.git
cd SmartWAN-Manager
cp .env.example .env
docker compose up -d --build
docker compose exec smartwan-manager node server/setPanelPassword.js admin 'replace-with-a-strong-password'

Open http://<host-address>:8888. In WSL 2, open http://localhost:8888.

Optional Tailscale networking on Linux with /dev/net/tun:

docker compose -f docker-compose.yml -f docker-compose.tailscale.yml up -d --build

Panel Administracyjny

Panel został stworzony dla ASUS RT-N18U z nieoficjalnym firmware gzenux/asuswrt-rtn18u w wersji 386.3_3. Reguły i presety SmartWAN, routerowy watchdog/failover, zarządzana polityka VPN/DMZ oraz hooki Merlin działają dalej po zatrzymaniu kontenera.

Panel musi pozostać uruchomiony dla monitoringu kraju/lokalizacji WAN, Cloudflare DDNS, Tailscale, trwałej archiwizacji zdarzeń, publicznego statusu/mapy sieci oraz powiadomień Aurelki.

Instalacja

Zalecane są: system Linux 64-bit, 2 GB RAM, 2 GB wolnego miejsca, Docker Engine z Compose v2, Git, stabilny LAN i dostęp SSH do routera. Skopiuj .env.example do .env, uruchom docker compose up -d --build, ustaw hasło komendą widoczną wyżej i otwórz port 8888 tylko w zaufanej sieci.

Pełna polska instrukcja, opis wszystkich zakładek, ekranu logowania, wymagań, Aurelki, Raspberry Pi, Ubuntu i WSL 2 znajduje się w README.
